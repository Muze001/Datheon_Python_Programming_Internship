 Datheon Python Programming Internship

Welcome to my project repository for the Datheon 2026 Python Programming Internship, organised by Datheon AI Systems & Automation Studio.

This repository contains four Python projects developed during the internship. Each project focuses on applying Python programming concepts to solve practical problems while improving my understanding of programming logic, problem-solving, file handling, data management and automation.

 Projects

 1. Hangman Word Guessing Game
A terminal-based word guessing game in which players attempt to identify a hidden word one letter at a time.

Key Features:
- Random word selection.
- ASCII hangman display.
- Tracks guessed letters.
- Prevents repeated guesses from reducing attempts.
- Win and loss conditions.

Technologies: Python, Random Module.

 2. Customer Support Chatbot
A rule-based chatbot designed to respond to common customer enquiries using predefined questions, answers and keyword matching.

Key Features:
- Recognises user intents.
- Responds to frequently asked questions.
- Provides business information.
- Handles unknown enquiries with fallback responses.
- Supports multiple conversation interactions.

Technologies: Python, Regular Expressions (`re`), JSON.

 3. Stock Portfolio Tracker
A Python-based application that allows users to enter stock information and view a summary of their portfolio performance.

Key Features:
- Accepts stock ticker symbols.
- Retrieves company information from the provided dataset.
- Records purchase prices and share quantities.
- Calculates portfolio values and performance.
- Generates portfolio summary data.

Technologies: Python, CSV.

 4. Automated File Organizer
A file management application that automatically sorts files into folders according to their file extensions.

Key Features:
- Organises files into appropriate categories.
- Supports documents, images, videos, audio, archives and code files.
- Creates destination folders automatically.
- Handles duplicate filenames.
- Tracks moved, skipped and failed files.

Technologies: Python, pathlib, shutil.

Getting Started

 Prerequisites

- Python 3 installed on your computer.
- Visual Studio Code or another Python-compatible editor.

 Running a Project

1. Clone this repository:

bash
git clone https://github.com/Muze001/Datheon_Python_Programming_Internship.git


2. Open the repository folder in Visual Studio Code.

3. Navigate to the project you want to run.

4. Open the terminal in that project folder.

5. Execute the relevant Python file. For example:

bash
python hangman.py


Replace hangman.py with the relevant filename when running another project.

Refer to each project's individual README for specific instructions.
